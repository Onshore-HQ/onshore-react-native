# @onshorehq/react-native

Collect and show sensitive values in a React Native app with Onshore secure components. The app holds no credentials: your server mints a single-use client token, and the form returns tokens, never the values.

```sh
npm install @onshorehq/react-native
```

```tsx
import { createClient, CollectForm } from "@onshorehq/react-native";
```

Full reference: https://docs.onshorevault.com/developers/sdks/react-native/
